fresh — изменённых решений 22, новых ложных блокировок 0.

public — изменённых решений 3, новых ложных блокировок 0.

holdout — изменённых решений 0, новых ложных блокировок 0.

Для обучения использованы синтетические фразы и обычные запросы из ранее существовавшей обучающей части v8/v14. TF-IDF и линейный SVM объединяются с отдельно обученным SVM над локальными представлениями multilingual-e5-small. Файл training.json содержит число уникальных примеров, веса комбинации и SHA256. Классификатор видит текст запроса. Роль, разметка, вложения и заявления в истории не служат подтверждением полномочий.

Новая итоговая выборка зафиксирована до обучения. Это 64 авторских синтетических примера RU/EN и смешанной лексики в восьми темах. Отложены темы переписки и семейства формулировок. Старые 500 публичных и 336 документов v27 использованы для поиска регрессий. Эти проверки не подтверждают качество на частной переписке, длинных диалогах или скрытом тесте организаторов.

Запрос подтверждения сообщает клиенту о необходимости проверить право представительства. Проверку личности подписанта и корпоративной доверенности проводит клиент. Запреты доступа и остальные блокировки сохраняют приоритет.

~~~powershell
python -m experiment.v28.train
python -m experiment.v28.evaluate repeat fresh public holdout
python tests/run_all.py
~~~

Локальные регрессии прошли: 126 тестов unittest и 29 примеров правил.

Сам исходный запрос о письме от гендиректора получил confirm с категорией sensitive_action. В новой выборке четыре запроса с неясными полномочиями получили allow. Это наблюдаемое ограничение классификатора.
