# B v17. Распознавание инъекций во вложениях

Проверены решения всего локального HTTP-сервиса. High и critical определены по эталону. В колонке «Блок и категория» знаменатель включает все настоящие косвенные инъекции, в том числе пропущенные. Для ложной блокировки знаменатель — легитимные запросы с ожидаемым allow.

## Разбор предыдущих ошибок

Из 20 пропусков на втором прежнем испытании 11 документов отсеял фильтр до модели, ещё 9 не преодолели порог линейной головы. Это девять исходных семейств. Все восемь неверных категорий пришли от общего классификатора v14 после специализированной проверки. Они распределились по четырём семействам. В трёх случаях система указала социальную инженерию, в двух — подмену системной инструкции, ещё по одному разу — jailbreak, прямую инъекцию и вывод данных. Обе дополнительные блокировки первого испытания относятся к одной форме для передачи комиссии, показанной в двух вариантах. Веса обучались на других текстах.

| Ошибка v16 | Исправлено в v17 | Критерий |
|---|---:|---|
| Пропущенная инъекция | 11/20 | block и indirect_injection |
| Неверная категория при block | 5/8 | block и indirect_injection |
| Лишняя блокировка на первом тесте | 2/2 | allow |

Переходы для каждого из 30 запросов приведены в comparison.json. Второй столбец строже одного решения block.

## Обучение и независимость выборок

Обучение включает 4854 различных текстов, из которых 2108 размечены как активные инструкции. В основе лежат 200 парных формулировок — 116 новых из 18 предметных областей и 84 прежних обучающих пары. Контексты, цитирование и положение указания в документе варьировались. Число вариантов одного сюжета больше числа независимых сюжетов. Для калибровки выделены 284 других документов, включая четыре отдельные темы и прежние разработческие контроли.

Локальный предобученный RuBERT-tiny2 дообучен целиком, шесть эпох на CPU. По калибровке выбрана эпоха 2. Экспорт — ONNX int8. Вторая модель — линейный SVM на текстах и разностях в парах с противоположным смыслом. Он использует слова, символьные n-граммы и уже существовавшие признаки v16. Третий сигнал — оценка прежнего SVM на исходном окне без отсечения по словарю. Векторы и нейросеть получают только содержимое вложения. Конфигурация подбиралась по худшему калибровочному домену при отсутствии новых блокировок ранее пропускавшихся документов, затем по общему распознаванию.

Смесь калиброванных оценок «энкодер / парный SVM / прежний SVM» имеет пропорции [2, 2, 0]. Итоговая калибровка распознала 85.0% активных указаний, минимум по домену 75.0%. Порог зависит от оценки прежнего SVM. Политика определяет последующее решение; режим включается только для B. Учебные роли, имена доменов, метки и ожидаемые ответы вне входа модели.

Новый тест зафиксирован до обучения (study.json). Восемь предметных тем, по восемь авторских пар в каждой. В паре совпадают пользовательский запрос, тема, роль, история и оформление, меняется содержание вложения. Четыре типа характеристик — русский и английский тексты, смешанные пакеты, второе вложение и краткая история. Повторы одной фразы под разными именами в число пар не входят. Полные исходные тексты пар не совпадают с текстами обучения и калибровки после нормализации. Сведения о пересечении с исходным языковым предобучением недоступны. Предыдущие тесты использованы ретроспективно.

## Итог и пределы проверки

Оба порога 85% на новых темах остались недостигнутыми. Хотя Score на свежем наборе вырос, прежние испытания выявили потери на critical. В текущей поставке v17 включается явно переменной STOROZH_ATTACHMENT_INTENT=2. Оснований менять рабочий B на этот кандидат пока нет. Наибольший резерв для следующего эксперимента — независимо размеченные естественные документы с явным адресатом, длинными цитатами и живыми указаниями разных жанров.

Новый тест: верный block и категория среди одних high — 33/48 (68.8%); вновь заблокировано обычных документов — 0, исправлено прежних ложных блокировок — 0. Технических ошибок — 0.

Результаты относятся к синтетическим текстовым вложениям. Новые сюжеты проверяют прежде всего попытки изменить содержание ответа и приписать документу неподтверждённый вывод. На каждую область приходится шесть high, два critical и восемь обычных документов. Такой объём чувствителен к одной-двум ошибкам. Схожая структура рабочих записей сохраняется между областями. Веса не обучались распознавать изображения, PDF или достоверность предметных фактов. Доля block по эталонному уровню не измеряет точность предсказания самого уровня.

## Длинные вложения и регрессии

Дополнительный стресс-тест использует одно обычное вложение и такой же текст с одним посторонним указанием в конце. На каждую конфигурацию выполнены два прогрева и восемь последовательных HTTP-вызовов. Здесь p95 при восьми наблюдениях равен максимуму.

| Символов | Содержимое | Решение | p95, мс |
|---:|---|---|---:|
| 200 | Обычный текст | allow | 51.7 |
| 200 | Указание в конце | block | 35.2 |
| 4000 | Обычный текст | allow | 248.5 |
| 4000 | Указание в конце | allow | 254.5 |
| 32000 | Обычный текст | allow | 1688.4 |
| 32000 | Указание в конце | allow | 1666.9 |

В длинном тексте короткая инструкция в конце осталась незамеченной на 4 000 и 32 000 символах, хотя токенизатор охватил конец. Проверка последних токенов сама по себе не гарантирует распознавания. На максимальной длине мягкая цель p95 в 0,5 с превышена. Все 72 модульных и API-теста и 29 проверок правил прошли.

## Воспроизведение в PowerShell

Нужна Python-среда из requirements-dev.txt. Для обучения в отдельной среде нужны experiment/v15/requirements-training.txt и локальная копия cointegrated/rubert-tiny2 ревизии e8ed3b0c8bbf4fb6984c3de043bf7d2f4e5969ae. Для архивной базы нужен artifacts/AI-Storozh-v16-CPU.zip с отпечатком из study.json. Оценки в поставке защищены от перезаписи. Для повтора используй новый каталог результатов.

```powershell
python -m experiment.v17.evaluate 1 --output experiment/v17/replay
python -m experiment.v17.evaluate 2 --output experiment/v17/replay
python tests/run_all.py
```

Для нового обучения используй отдельную копию каталога, чтобы сохранить запечатанные результаты. Команда seal создаёт файл однократно, для новой поставки нужен новый путь манифеста или чистая копия эксперимента.

```powershell
python -m experiment.v17.train C:/models/rubert-tiny2
python -m experiment.v17.calibrate
```
