# Проверка адресата инструкций во вложениях, B v25

## Диагностика 67 прежних блокировок

Разбор охватывает все 67 строк v24 с эталоном allow. На 20 приходятся энциклопедические материалы и ответы на вопросы. Ещё 14 — техническая документация, код и конфигурации, 10 — учётные записи и анкеты, девять — письма и обращения, пять — практические инструкции людям, пять — описательные статьи и разделы вопросов, четыре — учебные бюллетени по безопасности. Ошибки встречаются на 18 языках. Класс жанра присвоен вручную, исходная метка сохранена. В одном платёжном документе описанное действие адресовано другой системе автоматизации. Это неоднозначный случай для внешней бинарной разметки; исходная запись учтена в числителе ошибок. [Карточки всех 67 случаев](audit.json)

24 ошибочные блокировки выдала модель документов v20, 15 — модель категорий v14, девять — согласие предыдущих классификаторов. Среди остальных причин встречались буквальные совпадения в цитатах и инструкциях по защите. Наличие слова о безопасности плохо отличает учебный текст от обращения к текущему помощнику. [Исходные результаты v24](../v24/REPORT.md)

## Обучение и проверка

В обучении 1399 документов, для выбора параметров 405. Размечены адресаты для 1066 обучающих документов: 762 обращений к агенту, 108 инструкций людям и 196 справочных текстов. На остальных обучали только бинарные модели. Классификатор адресата использует слова и фрагменты слов, второй классификатор обучен также на разностях признаков 604 пар. Исходный многоязычный ONNX-энкодер заморожен. При валидации рассматривалась дополнительная SVM на смысловых векторах; выбранный для неё вес равен 0. Обработка выполняется на CPU. [Параметры и контрольные суммы](training.json)

На полном API выбранный вариант на 405 документах разработки заблокировал 234/255 угроз и 20/150 обычных документов. Эти данные использовались для выбора параметров, и их результат вынесен отдельно. [Ответы на этапе разработки](after-tuning.json)

108 размеченных инструкций людям образованы из 36 разных формулировок. Они размещены до, после и внутри описания. Темы и исходные фразы в контрольных авторских парах отделены от этих формулировок. При обучении не использовались прежние 67 ошибок.

Внешние контрольные данные исключены из обучения и выбора порогов. В панели 400 ранее не использованных документов из двух известных публичных корпусов, по 100 атак и 100 обычных от каждого. Отдельная проверка содержит 32 пары в восьми областях. Обе версии получают одинаковый запрос на краткое содержание и одно вложение. ## Перенос на PIarena

На 100 угрозах PIarena итоговый сервис пропустил 46. Из них 35 v24 ранее блокировала. В 46 пропусках окна полностью покрыли документ. У исходного энкодера отдельно, при пороге вероятности 0,5, положительную оценку имели 38 пропущенных записей. В 44 пропусках объединённая оценка оказалась в зоне снятия статистической блокировки. Это анализ зафиксированного кандидата после вскрытия выборки. [Сводка сигналов](transfer-audit.json)

Новые темы заданы авторскими парами на русском и английском. Четыре пары на тему дают большую статистическую неопределённость. Первичная внешняя панель включает англоязычные примеры PIarena и многоязычные синтетические документы. Бинарные внешние метки позволяют измерить блокировки, но не отдельно конкурсный high/critical.

Новый слой может снять только блокировку с подтверждённым статистическим происхождением при одиночном вложении и явной просьбе описать документ. Исходная команда с той же ролью проходит отдельную проверку. Если бюджет окон оставляет непрочитанный участок, предыдущая блокировка сохраняется. Ограничения доступа и запреты политики проверяет исходный сервис. Остальные режимы доступны для сравнения. ## Воспроизведение

Для запуска нужны зависимости проекта, локальные веса и конкурсный комплект в artifacts/astra_public. Для повторного измерения внешних документов восстановите данные командами подготовки Parquet из [отчёта v24](../v24/REPORT.md). Используйте новый тег, чтобы сохранить исходные измерения.

~~~powershell
python -m experiment.v25.lock
python -m experiment.v25.bench 12 repeat external control historic public
python tests/run_all.py
$env:STOROZH_VARIANT="B"
$env:STOROZH_ATTACHMENT_INTENT="12"
python -m uvicorn app.main:app --host 127.0.0.1 --port 8012
~~~

Для повторения обучения восстановите обучающие файлы v24 и граф v22 по инструкции v24. Затем запустите python -m experiment.v25.train encode и python -m experiment.v25.train fit в отдельной копии. Число потоков BLAS и OpenMP при подборе параметров — одно. Бенчмарк делает пять прогревочных запросов и измеряет полную последовательную HTTP-задержку на четырёх логических CPU.
