# Проверка v5 на новых областях

Три файла по 96 размеченных пакетов представляют музей, страхование и гостиницу. Во всех трёх случаях проверяется агент it_ops_agent с конкурсной матрицей доступа. На область приходится 24 смысловых семейства и 24 сочетания роли, операции и окружения, каждое в двух формулировках. Включены запросы на русском и английском, история, вложения и контрастные пары с разными ролями. Это синтетические примеры одного автора. Общие шаблоны между областями ограничивают разнообразие.

Разбиение development/holdout зафиксировано до обучения. Производные одного семейства проверяют перенос на другую формулировку, а не на совершенно новый тип намерения. В обучение категорий v5 добавлены 24 смысловых пакета музейной development-части к данным v4. Оценщик уровня обучен на 367 строках публичного development-разбиения и 48 музейных development-пакетах. Построчные прогнозы before.json и after.json позволяют сверить каждую ошибку. При разработке проверялись агрегированные промежуточные метрики, поэтому holdout не следует считать эквивалентом закрытого теста.

## Отложенные 144 пакета

| Метрика | v4 | v5 |
|---|---:|---:|
| Точное решение | 118/144 | 134/144 |
| Точная категория | 115/144 | 134/144 |
| Точный уровень | 76/144 | 134/144 |
| Строгая блокировка high/critical | 54/54 | 54/54 |
| Ложная блокировка обычного вопроса | 26/63 | 10/63 |

В v5 все три поля совпали у одних и тех же 134 пакетов. Ложные блокировки остаются в задачах подготовки публичного сообщения, передачи смены, проверки подлинности письма и анализа обычного вложения. Официальный HTTP-evaluator обработал все 144 строки без ошибки. p95 — 43,1 мс. Построчные решения, категории и уровни HTTP-ответов совпали с повторным вычислением ядра. В этом прогоне отдельного предварительного прогрева пятью официальными запросами не проводилось.

## Сопоставимость уровней

Для новой разметки ориентиры взяты из development-части public/dev. Например, оскорбления имеют low, извлечение инструкций — medium, утечка данных — critical. Удаление production-ресурса с разрешением администратора считается high, подтверждение обычного перезапуска — medium. Для распознанных операций оценка учитывает целевую среду и действие; для смысловых запросов используется оценщик, условный на предсказанной категории.

На прежних 133 публичных примерах v5 правильно определяет 125 решений, 116 категорий и 116 уровней (раньше 90 уровней). Строгий recall остаётся 34/38. Эти примеры использовались командой для разбора ошибок. На старой авторской проверке v4 из 92 пакетов действие и категория совпадают в 91 случае, уровень — в 70 (у прежней версии 77). В этом старом корпусе любое confirm размечено low, а извлечение промпта и abuse — high. Старая разметка сохранена; несовпадения нельзя скрывать при сравнении версий.

## Воспроизведение

~~~powershell
python -m experiment.v5.generate
python -m experiment.v5.train
python -m experiment.v5.measure artifacts/astra_public/repeat-v5.json
python tests/run_all.py
~~~

Для обучения нужны исходные материалы v4 и исходный публичный файл artifacts/astra_public/dev.jsonl. Для сравнения со старыми результатами measure также читает сохранённый v3-holdout.jsonl (подмножество публичного dev.jsonl с id из experiment/v3/split.json).
