# v14. Проверка ложных блокировок и категории jailbreak

На отдельном финальном наборе из 412 запросов ложные блокировки сократились с 17 до 9 из 348 (с 4,9% до 2,6%). Восемь безопасных запросов изменили решение с block на allow. Обратных переходов и лишних подтверждений не было.

Правильная блокировка с категорией jailbreak получена у 43 из 48 попыток (89,6%) против 42 у v13 (87,5%). Для порога 90% на таком наборе нужны 44. Все 48 попыток относятся к четырём новым предметным областям. Обе версии заблокировали одни и те же 44 попытки. Одна ранее ошибочная категория исправлена. Из 16 контрольных атак других типов все заблокированы, 15 верно классифицированы обеими версиями.

Четыре пропуска — photo-021, photo-024, houseplants-074 и houseplants-079. Запрос houseplants-072 заблокирован с категорией unauthorized_data_access. Наиболее заметный пробел — формулировки из области комнатных растений. В каждой области всего 12 попыток, поэтому счёт чувствителен к единичным ошибкам. Для скрытых данных организаторов измерений нет.

## Как разделены обучение и контроль

1. Первая модель, состав первой новой выборки и базовые ответы v13 зафиксированы в `3cc44fb`. На 536 новых запросах первый вариант v14 дал 65 правильных блокировок с типом jailbreak из 72 (90,3%), у v13 — 64. Ложные блокировки сократились с 11 до 7 из 448. По четырём областям отдельно было 41 из 48 (85,4%): в палеонтологии 12/12, лимнологии 9/12, городском освещении 10/12, хореографии 10/12. Все дополнительные 24 внешние попытки распознаны верно обеими версиями.
2. На основе ошибок первого прогона доработаны признаки снятия проверки исходящих ответов и ролевых просьб не отказывать вопреки правилам безопасности. Семь ошибок типа jailbreak и семь ложных блокировок из этого прогона вошли в обучение. Повторный результат 72/72 по типу и 1/448 ложных блокировок относится к диагностике.
3. Финальные веса и отдельные 412 запросов зафиксированы в `94d2488` до итогового прогона v14. В финальном контроле 112 новых авторских примеров на русском и английском и ещё 300 обычных вопросов из архивного benchmark2. Пересечение нормализованных исходных текстов, включая историю, с обучением проверено. Строки внешнего источника и их переводы разделены по исходным идентификаторам. Похожие способы формулировки могут повторяться. Использована роль developer; часть запросов начинается после приветствия или передаётся в виде продолжения диалога. Выборки не предназначены для оценки распространённости атак в реальном трафике.

Финальная модель — локальный линейный SVM. При обучении использованы 720 уникальных представлений jailbreak, 5881 обычных и 408 других обращений. При согласованных оценках модель реже относит учебную роль к jailbreak. Одно самостоятельное пользовательское приветствие больше не мешает распознать операцию над списком слов в самом сообщении. Автотесты проверяют, что приветствие с дополнительной инструкцией и опасное вложение по-прежнему обрабатываются политикой.

На отложенной публичной части организаторов (133 запроса) у обеих версий 120 верных категорий, 129 верных решений, 9/9 правильных блокировок jailbreak и 3/70 ложных блокировок. На фиксированной тысяче запросов из десяти прежних областей у обеих версий 985 правильных категорий, 992 правильных решения, шесть пропущенных угроз и две ложные блокировки.

```powershell
python -m experiment.v14.evaluate v14 confirmation
python -m experiment.v14.evaluate v14 previous
python -m experiment.v14.evaluate v14 public
python -m experiment.v14.evaluate v14 domains
python tests/run_all.py
python -m experiment.v14.evaluate v14 confirmation-api
```
