# Ложные блокировки и качество v6

Категориальная и бинарная модели переобучены на прежних данных v5 с дополнительными контрпримерами. Добавлены безопасная публикация статусов, передача смены, обучение противодействию мошенничеству, реагирование на случайное раскрытие данных, а также вредоносные запросы в схожем контексте. Уровень риска оценивает прежний компонент v5. Фразы для проверки и обучения хранятся отдельно.

| Набор | Ложные block среди эталонных allow, v5 → v6 | Решение v6 | Категория v6 | Уровень v6 | Строгий high/critical block, v5 → v6 |
|---|---:|---:|---:|---:|---:|
| 34 новых авторских примера | 2/22 → 1/22 | 33/34 | 33/34 | 33/34 | 9/9 → 9/9 |
| 144 прежних отраслевых примера | 10/63 → 1/63 | 143/144 | 143/144 | 143/144 | 54/54 → 54/54 |
| 133 примера публичной выборки разработки | 4/70 → 3/70 | 126/133 | 117/133 | 117/133 | 34/38 → 34/38 |

Новый небольшой набор сформирован до переобучения. Результаты промежуточных версий просматривались при разработке. Все числа получены на одинаковых строках до и после. Это диагностические измерения, а не оценка закрытого теста. Ложное срабатывание на новом наборе — приглашение на обучение распознаванию поддельных обращений. Реальные пропуски и ложные блокировки сохраняются.

Также исправлена несогласованность двух проверок учебного вопроса о рисках команды: правило безопасного объяснения учитывается и при проверке запрета из YAML. Регрессия распознавания требования действовать в роли ассистента без ограничений замечена при промежуточном прогоне и устранена. Ошибка загрузки или инференса обязательной модели больше не выглядит как успешное обнаружение атаки.

Воспроизведение из корня с материалами v4 и v5:

~~~powershell
python -m experiment.v6.train
python -m experiment.v6.evaluate repeat
python tests/run_all.py
~~~

Для пакетного API проверены исходный public_dataset.zip (500 строк за 9,73 с) и нагрузочный JSONL (3000 строк без разметки за 32,05 с). Нагрузочный файл содержал публичные входы с новыми идентификаторами. Проверены число и порядок результатов, идентичность решений при отсутствии меток и отсутствие добавлений в демонстрационный журнал. Это время загрузки и обработки пакета, а не официальная метрика задержки одиночного API.
