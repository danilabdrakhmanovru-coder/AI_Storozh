# Проверка на 1000 синтетических запросов

Проверена версия шлюза 677f2a4. Набор зафиксирован до получения предсказаний, SHA-256 файла cases.jsonl — 7ae67275b0f5a251a7f82b0baa01d6bc0d9f1eeeb87914718dc9800053bfc447. Генератор не загружает веса. Эталон для операций берётся из отдельно записанной матрицы конкурсной политики, для остальных запросов — из размеченных авторских сценариев. Корпус служит для оценивания.

Пять областей представлены поровну и используют одного агента it_ops_agent. В каждой области 72 операции (четыре инструмента, три роли, два окружения, три формулировки) и 128 семантических примеров (32 сценария по четыре варианта). Содержимое истории и вложений входит во вход API. Проверена уникальность сочетаний текста, роли, истории и вложений. Точных совпадений пользовательского текста с public/dev и текстами train.txt и v2/additional.txt нет после нормализации. Формулировки внутри семей и между областями родственны. Состав и уровни риска заданы автором, независимая экспертная разметка не проводилась.

Проверка шла последовательно через отдельный локальный экземпляр сервиса с временным журналом после пяти прогревочных запросов из public/dev. В evaluator переданы все 1000 строк. Выходы для каждой строки сохранены в predictions.jsonl без внутренних идентификаторов журнала.

Воспроизведение из корня репозитория (публичный комплект распакован в artifacts/astra_public):

~~~powershell
python -m experiment.synthetic1000.generate
python artifacts/astra_public/evaluate.py --data experiment/synthetic1000/cases.jsonl --endpoint http://127.0.0.1:8001/v1/check --report artifacts/astra_public/repeat-report.json --save-predictions artifacts/astra_public/repeat-predictions.jsonl
~~~

Результаты исходного прогона находятся в report.json и breakdown.json. На 370 угрозах high/critical получено 355 блокировок. Из 505 запросов с эталоном allow ошибочно заблокированы 217. Все 40 безопасных вложений и все 40 вложений с инъекцией получили block. Среди 105 действий с обязательным подтверждением 10 ошибочно получили allow. Замер относится только к зафиксированному корпусу и версии модели.
