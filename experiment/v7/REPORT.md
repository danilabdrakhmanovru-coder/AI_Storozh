# Качество конкурсного сторожа v7

На трёх прежних отраслевых наборах v7 заблокировал 63 из 1380 допустимых запросов (4,6%). В v6 таких блокировок было 366 (26,5%). Все 252 значимые операции получили подтверждение, все 1368 запрещённых — блокировку. Три набора используют общие шаблоны с отраслевой лексикой. Они служили для разбора ошибок и выбора изменений.

## Что изменилось

Классификаторы категорий и опасности обучены на дополнительных примерах обычной рабочей переписки, антифрод-предупреждений и запрещённых запросов со схожей лексикой. Для прямых одношаговых команд расширен разбор инструмента и имени сервиса. Решение для них берётся из действующей политики роли. Явное продолжение предыдущей просьбы пользователя проходит с её текстом и текущими правами. Остальная история и вложения сохраняются. Для англоязычных запросов учитывается сочетание просьбы создать поддельный документ с целью обмануть получателя или перенаправить оплату.

Из 63 оставшихся ложных блокировок 24 относятся к группе бланков и показателей, 22 — к публичным объявлениям, 17 — к пересказу служебных записок. Например, модель иногда принимает просьбу подготовить пустой бланк за мошенничество, а редактуру заметки для сайта — за подмену системных указаний.

На публичном контроле пропущены три jailbreak и один запрос категории harmful_content. Полнота строгой блокировки high/critical — 89,5%. Паромные примеры зафиксированы до обучения, промежуточные ошибки просматривались. Примеры про радиостанцию составлены после завершения обучения и использованы для итоговой проверки. Это небольшая ручная выборка. Качество на закрытых данных организаторов неизвестно.

## Воспроизведение

Для переобучения и публичного контроля нужен комплект организаторов с разделами, указанными в experiment/v4 и experiment/v5. Готовая модель входит в репозиторий. Для пакетного прогона запустите конкурсный API на локальном порту 8001. Скрипт проверяет SHA-256 входов, передаёт только идентификатор, текст и контекст, затем сверяет число и порядок ответов с эталоном.

~~~powershell
python -m experiment.v7.train
python -m experiment.v7.evaluate after
python -m experiment.three_domains.run --output experiment/v7/three_domains
python tests/run_all.py
~~~
