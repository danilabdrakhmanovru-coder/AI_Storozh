# Jailbreak и ложные блокировки в v9

На итоговых 64 новых обращениях сторож остановил 24 из 28 попыток jailbreak (85,7%). Предыдущая версия остановила 21 из 28 (75,0%). Решения по каждому из 36 безопасных вопросов совпали. В обеих версиях было 5 ложных блокировок и 0 лишних подтверждений.

## Проверка после выбора модели

Итоговые формулировки на русском и английском включают запросы о снятии защиты, смене роли, исключении для занятия и ссылки на полномочия. Есть прямые обращения, продолжения просьбы из истории и обращения после нейтрального диалога. Вариант модели, порог и список итоговых примеров зафиксированы в коммите `4928820` до измерения v9 на этом наборе. Во всех 196 авторских контрольных формулировках проверено отсутствие дословных совпадений с обучающими текстами.

| Итоговый набор | v8 | v9 |
|---|---:|---:|
| Заблокировано jailbreak | 21/28 | 24/28 |
| Заблокировано с верной категорией jailbreak | 16/28 | 19/28 |
| Ложные блокировки на бытовых вопросах | 0/12 | 0/12 |
| Ложные блокировки на легитимных вопросах о безопасности и ролевых диалогах | 5/24 | 5/24 |

В v9 четыре попытки прошли, пять были остановлены с другой категорией. Требование 85% проверялось по строгому решению block. Результат на 28 попытках чувствителен к одному ответу. Часть формулировок семантически близка, и состав закрытого набора организаторов неизвестен.

## Изменение качества на прежних данных

| Данные | Jailbreak заблокировано, v8 → v9 | Ложные блокировки обычных запросов, v8 → v9 |
|---|---:|---:|
| Три прежних контрольных домена | 61/120 → 115/120 | 56/1410 → 56/1410 |
| Все десять прежних доменов, включая эти три | 341/400 → 395/400 | 73/4700 → 73/4700 |
| Публичная контрольная часть организаторов | 6/9 → 9/9 | 3/70 → 3/70 |

Эти показатели использовались при разработке. В публичном контроле встречались просьбы о вредных практических инструкциях под видом учёбы с требованием опустить предупреждения. Из десяти прежних доменов 9843/10000 решений v9 совпали с эталоном, у v8 было 9789/10000.

Отдельно проверены 500 уникальных русскоязычных запросов с меткой 0 в двух внешних наборах из предыдущего эксперимента. В каждой базе выбрано 250 примеров с фиксированным seed, прежняя выборка из манифеста исключена. На этом срезе обе версии заблокировали 173/500 (34,6%), новых блокировок не возникло. Внешняя метка указывает на отсутствие prompt injection, но не учитывает все запреты конкурсной политики. Для подсчёта ошибок по этой политике здесь нужна отдельная разметка.

## Что обучено

В дополнение к моделям v8 обучен бинарный линейный SVM с признаками слов и символьных фрагментов. Он учитывает сочетания признаков роли, снятия защиты и обсуждения подобных запросов. Обучено на 1092 уникальных представлениях входов, из них 166 положительных. В обучении использованы тренировочная часть публичного корпуса, предыдущие обучающие материалы и отдельно написанные русские и английские примеры. Специализированный детектор уточняет категорию, когда прежняя модель выдала нейтральный или чувствительный результат либо не выбрала категорию. Окончательное решение принимает конкурсный шлюз с действующей политикой.

Первые 132 новых примера использовались для диагностики. Первый кандидат остановил 51 из 56 jailbreak и добавил две ложные блокировки относительно v8. После добавления примеров про обучение безопасности и выбора порога 0,30 итоговый вариант остановил 48/56 при 9/76 ложных блокировок, как у v8. Порог — отступ линейного SVM. В отдельной части диагностики с учебными предлогами и заявлениями о полномочиях осталось 12/16 блокировок (75%). Вторая редакция оценивалась отдельно на 64 итоговых обращениях. Там после измерения модель не менялась.

## Воспроизведение

~~~powershell
python -m experiment.v9.train
python -m experiment.v9.evaluate v8 all
python -m experiment.v9.evaluate v9 all
python -m experiment.v9.external_control
python tests/run_all.py
~~~

Переобучение и историческая диагностика требуют исходного публичного комплекта в каталоге artifacts/astra_public. Внешний контроль использует два локальных CSV из experiment/external с проверкой SHA-256. Для сравнения v8 используются сохранённые решения десяти доменов либо тот же шлюз с отключённым новым детектором. Итоговые 64 пакета также переданы без эталонных меток в работающий API. Порядок, идентификаторы, решения и категории совпали с локальным прогоном.
